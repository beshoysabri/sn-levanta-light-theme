Levanta Light

A light theme with a lavender accent, the daytime twin of Levanta Dark — the note you write set in Karla and IBM Plex Sans Arabic, with arrows that work in both.

v2.8.1

Install

https://beshoysabri.github.io/sn-levanta-light-theme/ext.json
  1. Open the Standard Notes desktop app → Preferences → Plugins
  2. Paste the link under Install Custom Plugin, at the bottom
  3. Pick Levanta Light from the Appearance menu

Use the desktop app for the install: the web app refuses plugin links from any self-hosted theme. Installed themes sync with your account, so it reaches the web app from there.

Pair it with Levanta Dark

Install Levanta Dark too, then turn on Preferences → Appearance → Use system color scheme and pick Levanta Light as the Automatic Light Theme and Levanta Dark as the Automatic Dark Theme. Standard Notes then follows your OS between the two. That choice is stored per device, so set it once on each.

Written in Karla and IBM Plex Sans Arabic

Weekly notes · ملاحظات الأسبوع

The note you write is set in Karla — italics included — and Arabic in IBM Plex Sans Arabic. The rest of the app stays in Inter. Arrows are typed: plan -> build -> ship, and if => then.

نكتب الملاحظات بخط IBM Plex Sans Arabic، والإنجليزية بخط Karla. الخطة -> التنفيذ -> الإطلاق، والسهم يشير باتجاه القراءة.

Nothing has to detect Arabic: the browser picks a font per character, and Karla has none, so Arabic falls through to Plex.

Code keeps its monospace face, and no arrows:

const next = a -> b;

If this note renders in Karla and Plex with real arrows, the woff2 files resolved over Pages. This page loads them by relative path because a browser fetches it directly; the theme names the same files by absolute URL, because Standard Notes inlines theme CSS and a relative path would resolve against the app's own origin.

Notes

The desktop app needs the fonts installed. It sets default-src 'self' blob: with no font-src, so it refuses to download any webfont — a data: URI included. Install the font pack (Inter, Karla, IBM Plex Sans Arabic and Levanta Arrows; on Windows, right-click → Install for all users), then quit and reopen the app. The web app and the iPhone and Android apps download the fonts on their own.

A mirror of Lavender. Each grey sits at the same contrast from the base as its twin in the dark theme: the #252525 sidebar becomes #f5f5f5, #2a2a2a borders become #eeeeee, and the #eeeeee text becomes #2a2a2a — 14.4:1 on its base in both. Hover greys are a step lighter than an exact mirror, so the selection stays the loudest thing in a list.

Selection is a lavender wash, not a grey bar. Standard Notes paints the selected tag and the selected note with the colour it also uses for hover. Here hover stays grey and the selected row gets an 18% lavender tint, as in Lavender — with the sidebar label in the darkened #5446c9, which reads at 5.0:1 on that tint where the accent itself would manage 3.6:1.

The accent is deep enough that text on it is white again (4.9:1), as in native Light — primary buttons, the new-note button, the Daily view's date tiles. Like the Copy button above.

The Daily notebook uses the app's danger token for today's date and the create-note button, which reads red on a lavender theme. Those specific elements are repainted with the accent — destructive controls stay red.

Arrows in both directions. Karla has no arrow ligatures, and Inter's never form in Arabic: a right-to-left run mirrors > into < before ligatures are looked up. Levanta Arrows, a 2 KB font with Karla's own - < = > and Inter's arrows, handles both — in an Arabic paragraph -> points the way the text reads. <= and >= are left alone.
